# Supplement B: LLM Reasoning Pattern Analysis

## Overview

This supplement contains the comprehensive qualitative analysis of how different LLM architectures reason when applying the rubric (Experiment 4).

## Relationship to Main Paper

This analysis is **tangential to the core claims** about reliability and validity. It explores an interesting computational linguistics question: How do different LLMs explain their reasoning, and does more detailed reasoning correlate with consistency?

## Key Finding: The Consistency-Reasoning Paradox

- **GPT-4.1**: Most consistent scores but most superficial reasoning
- **o3 models**: Least consistent but show deeper analytical thinking  
- **GPT-4o**: Balanced performance (chosen for CHAT)

## Why This Was Moved to Supplement

While scientifically interesting, this analysis:
1. Doesn't directly strengthen reliability or validity claims
2. May raise questions about whether consistency equals quality
3. Could distract from the core message about CHAT's reliability

## Scientific Value

For researchers interested in:
- LLM explainability in assessment contexts
- Trade-offs between consistency and reasoning depth
- Model selection criteria beyond performance metrics

This analysis provides rigorous statistical evidence (chi-square, Kruskal-Wallis, correlation analysis) about reasoning quality differences across models.
